15. Test de verificare – GitHub
1. Ce este un depozit și ce conține în plus față de un folder obișnuit?
Un depozit (repository) este un spațiu în care se păstrează fișierele unui proiect și istoricul modificărilor acestora.

În plus față de un folder obișnuit, un depozit Git conține istoricul versiunilor, înregistrat prin commit-uri, și informații despre modificările efectuate.

2. Ce este un commit? Ce informații înregistrează GitHub?
Un commit este o înregistrare a unei versiuni a proiectului la un anumit moment.

La fiecare commit se înregistrează:

modificările efectuate asupra fișierelor;

autorul modificărilor;

data și ora;

mesajul care descrie modificările;

un identificator unic al commit-ului.

3. Care sunt regulile GitHub pentru parolă și numele de utilizator?
Parola: trebuie să respecte cerințele de securitate GitHub, inclusiv lungimea minimă și verificările de securitate aplicate la crearea contului. Este recomandată o parolă lungă și unică.

Numele de utilizator: poate conține litere, cifre și cratime (-), trebuie să aibă între 1 și 39 de caractere și nu poate începe sau se termina cu o cratimă. Nu sunt permise spațiile și caracterul _.

4. Care nume de utilizator sunt acceptate de GitHub?
ana-ionescu – acceptat, deoarece conține litere și o cratimă între cuvinte.

-ana- – neacceptat, deoarece începe și se termină cu o cratimă.

ana ionescu – neacceptat, deoarece conține un spațiu.

ana_ionescu – neacceptat, deoarece conține caracterul _, care nu este permis.

5. Ce se face pe calculatorul din laborator la sfârșitul orei și de ce?
Se verifică dacă fișierele sunt salvate și încărcate corect în depozitul GitHub, se fac modificările necesare și se închide sesiunea de lucru. Calculatorul se lasă ordonat și pregătit pentru următoarea oră, iar contul personal este protejat prin deconectare.

6. Prin ce diferă un depozit Public de unul Private? Care se alege pentru portofoliu?
Public: poate fi văzut de oricine pe internet.

Private: poate fi accesat numai de proprietar și de persoanele autorizate.

Pentru un portofoliu școlar care trebuie să fie vizibil profesorilor și altor persoane, se alege de obicei un depozit Public, fără a publica date personale sau materiale confidențiale.

8. Care sunt limitele la încărcarea din browser?
La încărcarea fișierelor prin interfața web GitHub:

Mărimea unui fișier: maximum 25 MiB.

Numărul de fișiere: maximum 100 de fișiere la o singură încărcare.

9. Afișul a fost corectat. Cum se încarcă varianta nouă?
Se încarcă fișierul corectat în același folder și cu același nume ca fișierul vechi, apoi se confirmă modificarea printr-un commit.

Varianta veche este înlocuită în versiunea curentă a depozitului, dar poate fi recuperată din istoricul commit-urilor, dacă a fost înregistrată anterior.

12. Care sunt pașii de activare a GitHub Pages? Ce fișier este prima pagină?
Pașii sunt:

Se deschide depozitul pe GitHub.

Se accesează Settings.

Se selectează Pages.

La Build and deployment, se alege publicarea dintr-o ramură (Deploy from a branch).

Se selectează ramura, de regulă main, și folderul rădăcină (/ (root)), dacă acolo se află pagina.

Se apasă Save și se așteaptă publicarea site-ului.

Prima pagină a site-ului este, de regulă, fișierul index.html.
